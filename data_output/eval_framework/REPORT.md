## 11. Failure cases and error analysis

- Concepts: kg_extract drops heading-only terms (SSS, SAS, ASA, AAS, Special Right Triangles) via the frequency filter and common words (Area, Similarity) via the common-word filter; the rule pipeline drops 2-letter acronyms (HL) and relies on a hard-coded geometry list.
- Prerequisite: extracted edges hit few AL-CPL pairs; 31 of 54 kgx_v2 prerequisite edges point backward in the book.
- Similarity (rule_v3): 43 of 46 edges involve congruence wording; 42 have evidence containing 'congruent to', which the keyword path maps to Similarity (45 of 46 came from the keyword path).
- Part-of (kgx_v2): 18 edges have the kind-of name pattern, e.g. *acute triangle → triangle*, *angle → inscribed angle*, *angle → straight angle*, *area of a circle → circle*. Some are genuine type confusions (a kind of X stored as part of X, which is Extension); others are heuristic false positives (e.g. a property such as an area 'of a circle'). Only annotation can tell them apart.
- See section 6 and `relations/edge_checks_<kg>.csv` for every flagged edge.

## 12. Claims supported by the evidence

- Supported [GT]: book order is the strongest prerequisite signal in this book; the rule and LLM KGs' prerequisite edges are near chance on AL-CPL; the AHP weight ranks AL-CPL prerequisites above random, mostly through co-occurrence.
- Not supported: any precision/recall for Part-of, Application, Similarity or Extension; validity of the AHP weight for those types or for 'educational relevance'; direction correctness from any weight; question-level gap detection; generalisation beyond this textbook.
